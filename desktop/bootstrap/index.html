桥接核心机制说明

  • 同步恢复与旧键清除：启动时先以原生方法清空旧键并一次性回填全量字符串键（包含胶囊指针、动态UUID与排行榜等），绝不只筛选前缀。
  • 100ms 防抖合并：密集写入自动合并为单次快照提交，减少跨进程 IPC 损耗。
  • 单串行落盘链：快照落盘走严格单 Promise 串行队列，保证 Revision 递增不乱序；仅在 Rust 确认后推进。
  • 16MiB 保护与 UTF-8 校验：严格按 UTF-8 字节计算快照体积，超限明确报告 flush_failed 并拒绝提交，避免静默截断。
  • 原型防污染保护：底层快照映射均使用无原型对象（Object.create(null)），杜绝 __proto__ 原型链污染。
  • 优雅退出保护（Freeze / Thaw）：退出前调用 freeze() 取得最终快照；若用户在确认框取消退出，通过 thaw() 恢复正常写入与脏标记合并，不丢失数据。
